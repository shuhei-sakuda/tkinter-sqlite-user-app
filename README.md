# Tkinter × SQLite ユーザー管理アプリ

Python学習の実践として制作した、ユーザー名を管理するGUIアプリです。

TkinterでGUI画面を作成し、SQLiteと連携してユーザー情報の登録・削除・編集・更新を行えるようにしました。

SQLiteにデータを保存するため、アプリを終了して再起動しても登録したユーザー情報が保持されます。

## 主な機能

-   ユーザーの登録
-   ユーザーの削除
-   ユーザーの編集
-   ユーザー情報の更新
-   SQLiteへのデータ保存
-   アプリ起動時の保存データ読み込み
-   未入力・未選択時の警告表示

## 使用技術

-   Python
-   Tkinter
-   SQLite
-   SQL

## 実装したこと

### GUI

Tkinterを使用して、ユーザー一覧を表示するListbox、名前を入力するEntry、登録・削除・編集・更新を行うButtonを作成しました。

### SQLiteとの連携

SQLiteにユーザー情報を保存し、以下のSQL操作を実装しました。

-   `INSERT`：ユーザーの登録
-   `SELECT`：ユーザー情報の取得
-   `UPDATE`：ユーザー情報の更新
-   `DELETE`：ユーザーの削除

### ListboxとSQLiteのIDの対応

Listbox上の位置とSQLiteのIDは一致するとは限らないため、SQLiteのIDを
`user_ids`
というリストで管理し、画面上の選択位置から対応するデータベースのIDを取得できるようにしました。

### アプリ終了時の処理

ウィンドウを閉じる際にSQLiteとの接続を閉じてから、アプリを終了する処理を実装しました。

## 実行方法

Pythonがインストールされている環境で、以下を実行します。

``` bash
python3 user_app.py
```

初回起動時に `new_users.db` が作成され、`users`
テーブルも自動的に作成されます。
